# Assignment 17 - GraphQL API
Integration of Apollo Server with Express and Mongoose:
- **Queries**: `getAllPosts`, `getPostById(id)`, `getAllUsers`
- **Mutations**: `createUser`, `createPost`, `likePost`

## Run
1. `npm install`
2. `npm start`
3. Open Apollo Sandbox in browser at `http://localhost:3000/graphql`
